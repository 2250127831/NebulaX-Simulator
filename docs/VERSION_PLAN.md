# NebulaX-Simulator 版本规划

## V1（当前，已定版）

**定位**：单机、纯内存、确定性的市场微观结构仿真平台。基于历史 ITCH 回放，模拟"委托 → 交易所撮合 → 广播 → 交易系统订阅"的完整链路。

### 已实现功能

| 能力 | 状态 |
|---|---|
| 撮合引擎（价格/时间优先、部分成交、撤改单、IOC/DAY） | ✅ 迁移自 NebulaX |
| 委托进交易所 → 广播 → 交易系统订阅（时序不变量） | ✅ |
| 分段回放 + `segment_size` 段边界策略插入窗口 | ✅ |
| 可插拔策略（CRTP 编译期多态，吸收自 Trader） | ✅ |
| 加权净投票仲裁（primary/weights/vote_threshold 配置） | ✅ |
| 价格单位统一 1/10000 tick，PnL 数值可核对 | ✅ |
| 指标输出：equity.csv / trades.csv（含滑点）/ orders.csv / summary.txt（夏普/索提诺/卡玛/胜率/盈亏比） | ✅ |
| 确定性：同一配置两次运行逐字段一致 | ✅ |
| 测试：重演等价 / 价格单位 / 仲裁（ctest） | ✅ |
| 迁移 bug 修复：NebulaX 撤单双扣减（含修复建议文档） | ✅ |

### V1 已知边界

- **单线程**：撮合并发能力（不同 symbol 并行）未启用，为确定性回放有意取舍。大样本 874 万消息约 2 分 45 秒（~5.3 万委托/s）。
- **数据依赖**：测试用生成小样本（`gen_test_data.py`）+ 本地大样本软链。策略结果跑在 `itch_sample.bin`（挂撤演练型，成交稀少），**策略结论需真实完整 ITCH 逐笔数据**。
- **无外部实时观测**：仅事后 CSV，无共享内存实时采集。

## V2 候选路线（未排期）

| 方向 | 内容 | 动机 |
|---|---|---|
| 性能优化 | 撮合 `std::map` 价格档 → hash；减少内存池分配 | 单线程吞吐是当前瓶颈 |
| 真实数据接入 | 逐笔 ITCH 文件格式说明 + 转换脚本 | 让策略结论可信 |
| 多线程并行 | 不同 symbol 分片到 worker 线程（对齐 Trader 线程模型） | 性能 + 并发正确性探索；需权衡确定性 |
| 外部观测 | 共享内存暴露计数器（对齐源项目 metrics） | 边跑边看 |
| 更多策略 | 内置 momentum/trend 等 + 策略参数 config 化 | 研究平台扩展 |
